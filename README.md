# StockDesk — склад оптовой фирмы

УП.02, вариант 17. Настольное приложение для учёта заявок на отгрузку. Менеджер оформляет заявку и назначает кладовщика. Кладовщик комплектует заказ и указывает сумму. Менеджер отмечает отгрузку, администратор управляет пользователями и выгружает отчётность.

## Проверить проект

1. Скачайте исходники через **Code → Download ZIP** или клонируйте репозиторий.
2. Установите Visual Studio 2022 (17.8+) или 2026, SDK .NET 8 и рабочие нагрузки «Разработка классических приложений .NET» и «Разработка ASP.NET и веб-приложений».
3. Откройте [StockDesk.sln](StockDesk.sln), выберите профиль **StockDesk** и нажмите **F5**. Если профиля нет в списке, назначьте **StockDesk.Desktop** запускаемым проектом. Приложение само запускает API и открывает окно входа.

| Роль | Учебный логин | Учебный пароль |
| --- | --- | --- |
| Администратор | `admin` | `StockDemo17!` |
| Менеджер | `manager` | `StockDemo17!` |
| Кладовщик | `worker` | `StockDemo17!` |

При первом запуске создаётся локальная база SQLite с 45 вымышленными покупателями и 45 заявками. Используйте [руководство](docs/user-guide.md), чтобы проверить поиск, статусы, роли и обмен файлами.

## Правила работы с ветками

`main` содержит версии для сдачи, `develop` служит для интеграции. Изменения делаются в `feature/*` или `fix/*` и попадают в `develop` через pull request. Выпуск готовится в `release/*` и сливается в `main` после CI. Такой процесс сохраняет отдельную ветку с проверенной версией и позволяет готовить материалы практики отдельно. Работа индивидуальная.
