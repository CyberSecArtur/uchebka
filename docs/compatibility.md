# Совместимость и проверка выпуска

| Конфигурация | Состояние |
| --- | --- |
| Windows x64, исходники, Visual Studio 2026 | Подтверждены сборка и запуск окна входа под отладчиком. |
| Windows x64, Visual Studio 2022 17.8+ с SDK .NET 8 | Предусмотрено решением и профилем запуска. Запуск в самой VS 2022 требует отдельной проверки. |
| Windows x64 без Visual Studio | Для этого случая предназначен архив Releases. |
| GitHub Actions, Windows x64 | Фактическое состояние по ссылке на [прогоны](https://github.com/CyberSecArtur/uchebka/actions). |

При запуске готовой автономной сборки папку `server` оставляют рядом с клиентом. На других архитектурах и отдельных редакциях Windows проверка не проводилась.
