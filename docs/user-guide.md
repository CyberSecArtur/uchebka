# Руководство пользователя

Откройте [инструкцию запуска и учебные данные](../README.md#проверить-проект). Для запуска готового ZIP распакуйте архив целиком и откройте `StockDesk.Desktop.exe`. Папка `server` должна находиться рядом с программой.

1. **Менеджер.** Откройте «Покупатели», добавьте покупателя или импортируйте CSV. Во вкладке «Заявки» нажмите «Новая заявка», укажите покупателя и товары. Выберите созданную запись, нажмите «Изменить статус», укажите «Комплектуется» и кладовщика.
2. **Кладовщик.** Войдите под `worker`, выберите назначенную заявку, нажмите «Изменить статус», выберите «Собрана» и укажите сумму.
3. **Менеджер.** Откройте собранную заявку и смените статус на «Отгружена». До отгрузки заявку можно отменить.
4. **Администратор.** Вкладка «Пользователи» открывает список и добавление сотрудников. Во вкладке «Отчётность» доступны сводка и выгрузки в CSV, JSON, XML.

Поиск по номеру, адресу, покупателю или товарам применяется при вводе. Кнопки над таблицей сразу переключают статус. «Выйти» находится внизу справа. Если вход отклонён, проверьте заголовок окна «StockDesk · Склад оптовой фирмы» и скопируйте учебный пароль из README.
