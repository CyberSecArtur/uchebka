# Доступ и диагностика

- Учебные учётные записи создаются в локальной базе. Пароли сохраняются как хеши через PasswordHasher.
- JWT подписывается ключом, который генерируется при запуске локального API. Токен действует до четырёх часов или до перезапуска API. Выход удаляет токен из WPF-клиента.
- API повторно сверяет роль пользователя и назначенного кладовщика. Вкладки WPF помогают навигации, права проверяются отдельно на сервере.
- Вход ограничен 15 попытками в минуту для одного адреса. Импорт ограничен 256 КиБ. CSV экранирует значения, которые могут стать формулами в таблице.
- Сервер записывает метод, путь, код ответа и длительность запроса в консольный журнал. Клиент замеряет обновление данных через Stopwatch.
- Публичный доступ к API не предусмотрен. Учебный пароль в README предназначен только для демонстрационной базы.

При отказе входа приложение оставляет форму открытой. Если локальный API не запустился, приложение сообщает об ошибке до показа формы. При конфликте версии записи API возвращает 409, после чего следует обновить таблицу.
