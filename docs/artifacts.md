# Артефакты и обмен данными

| Артефакт | Формат и место хранения |
| --- | --- |
| Исходники и настройка запуска | C#, XAML, MSBuild, `StockDesk.sln`, `StockDesk.slnLaunch`. |
| Протокол WPF и API | Локальный HTTP, JSON, JWT в заголовке Authorization. |
| Импорт покупателей | CSV UTF-8, заголовок `name;address`. [Пример](customers.csv) содержит и корректные данные, и строку для демонстрации диагностики. |
| Выгрузка заявок | CSV UTF-8 с BOM, JSON, XML. Выдаётся весь доступный администратору список. |
| Данные программы | SQLite в `%LOCALAPPDATA%\StockDesk`, либо в каталоге `STOCKDESK_DATA`. |
| Сборки, отчёты тестов | ZIP в Releases, TRX в GitHub Actions. |

Импорт имеет лимит 256 КиБ, возвращает число добавленных записей и номера ошибочных или повторных строк. Отчёт содержит номер, покупателя, адрес, описание товара, кладовщика, статус, цену и даты. CSV экранирует кавычки, разделители в текстовых полях и начальные символы формул.
