# Проверка StockDesk

Проверяйте сценарии изменения данных на отдельной учебной базе. Результаты ниже получены при проверке проекта на Windows с .NET 8 Runtime. Переходы из любых других сочетаний проверяются тестами `StockDesk.Tests`.

| ID | Требование | Сценарий | Факт |
| --- | --- | --- | --- |
| T01 | F01 | Войти под каждой ролью, затем выйти | Все три роли открылись, при выходе сбросились фильтр и поиск. |
| T02 | F01 | Ввести неверный пароль | Окно входа показало ошибку. |
| T03 | F02 | Создать заявку под менеджером | Появилась запись «Создана». |
| T04 | F03 | Назначить кладовщика, открыть его журнал, указать сумму | Запись появилась у назначенного кладовщика и перешла в «Собрана». |
| T05 | F04 | Отгрузить собранную заявку и отменить другую | Получены «Отгружена» и «Отменена». |
| T06 | F05 | Выбрать «Отгружена» и ввести текст, включая пустую выдачу | Фильтрация и поиск применились сразу, регистр и внешние пробелы учтены. |
| T07 | F06 | Добавить покупателя и передать корректный CSV в API | Записи сохранены, импорт вернул число добавленных строк. |
| T08 | F07 | Добавить сотрудника под администратором | Новый сотрудник появился в списке и смог войти. |
| T09 | F07 | Запросить выгрузки через API | В CSV, JSON, XML найдена тестовая отгрузка. |
| T10 | F03, F08 | Проверить список второго кладовщика и отчётность | Чужая заявка не отображалась. Итоги обновились после добавления и отгрузки. |

Запуск под отладчиком подтверждён в Visual Studio 2026. Visual Studio 2022 предусмотрена в конфигурации, проверка в самой IDE отложена до машины с этой версией.
